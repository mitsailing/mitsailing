Class details

Mid-Week 1-2-3 is for MITNA members with little or no sailing experience. Pick a week when you can attend all three evenings; the course is built as one sequence.

What happens each night

Class 1

Pavilion, rigging, and dock demo

Tour the Pavilion, learn the Tech Dinghy setup, practice key knots, and see launching, landing, tacking, and gybing before the next on-water sessions.

Class 2

First sailing session

Rig your boat, review the course, launch from the dock, sail to a mark, tack, return, and land with dock and motorboat coaching.

Class 3

Practice and next skills

Keep sailing with coaching. The focus may shift with wind and class size, but safety and usable sailing skills come first.
